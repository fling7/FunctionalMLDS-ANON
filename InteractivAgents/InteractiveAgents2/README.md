# Minimal Unity source snapshot

This directory contains only the current source and configuration needed to inspect
the FunctionalMLDS Unity integration and to run the artifact's static contract check.

Included are the pinned package/version records, V2 model/runtime classes, scene
binding components, the QuickAgent bridge, project-wizard/runtime support classes,
and deterministic editor smoke sources. Scenes, generated models, characters,
textures, samples, recordings, screenshots, user-test components, and editor caches
are intentionally absent.

This is therefore a review-focused source snapshot, not a redistributable full Unity
project or a standalone playable build.
